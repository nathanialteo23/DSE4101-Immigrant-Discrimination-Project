This script fits the restricted-treatment causal forest (Type 0 vs. Type 1, Chinese/Indian/Pakistani/Canada – the same base treatment as interaction1_language_signal.Rmd), then presents its heterogeneity the way Rehill’s (2025) review describes as the most common approach in the literature (Section 5.3): plotting individual CATE estimates against each covariate. Since our covariates are binary, this takes the form of boxplots/group comparisons rather than a smoothed continuous curve.

df <- read_dta(data_path)

# haven::read_dta() preserves Stata's variable/value labels as an extra
# "haven_labelled" class on top of each numeric column. lm_robust() (used
# elsewhere in this project) silently strips this when building its model
# formula, but grf::causal_forest() does not -- its internal validation
# calls is.vector() on Y and W, which returns FALSE for anything carrying
# extra attributes, including haven_labelled. zap_labels() removes that
# metadata so every column becomes a plain numeric vector.
df <- haven::zap_labels(df)

Sample construction

Identical restriction to the interaction models: Type 0 vs. Type 1, restricted to Canada/Chinese/Indian/Pakistani names. accreditation, legal, and reference are dropped entirely from the covariate set – they are structurally constant (always 0) in this subsample, since those characteristics only exist for resumes claiming foreign credentials, and a zero-variance covariate cannot be split on.

df_cf <- df %>%
  filter(
    type %in% c(0, 1),
    name_ethnicity %in% c("Canada", "Chinese", "Indian", "Pakistani")
  ) %>%
  mutate(
    W  = as.numeric(type == 1),
    Y  = callback,
    female                 = ifelse(is.na(female), 0, female),
    ba_quality              = ifelse(is.na(ba_quality), 0, ba_quality),
    extracurricular_skills  = ifelse(is.na(extracurricular_skills), 0, extracurricular_skills),
    language_skills          = ifelse(is.na(language_skills), 0, language_skills),
    ma                      = ifelse(is.na(ma), 0, ma),
    same_exp                = ifelse(is.na(same_exp), 0, same_exp),
    exp_highquality         = ifelse(is.na(exp_highquality), 0, exp_highquality),
    fall_data               = as.numeric(as.factor(fall_data))
  )

covariate_names <- c("female", "ba_quality", "extracurricular_skills",
                      "language_skills", "ma", "same_exp", "exp_highquality")

# fall_data is included as a covariate to help the forest's internal Y.hat/W.hat
# regressions, but is not one of the substantive covariates we plot CATEs against.
#
# X, Y, and W are explicitly coerced here rather than relying on zap_labels()
# alone: haven columns can carry a *separate* singular "label" attribute (the
# Stata variable description) in addition to the "labels" (value labels)
# attribute that zap_labels() removes. is.vector() -- which grf's internal
# validate_observations() uses -- returns FALSE if ANY attribute remains,
# regardless of which one. as.numeric() and data.matrix() strip everything
# unconditionally, guaranteeing plain vectors/matrix no matter what metadata
# haven left behind.
X <- data.matrix(df_cf[, c(covariate_names, "fall_data")])
Y <- as.numeric(df_cf$Y)
W <- as.numeric(df_cf$W)
clusters <- as.numeric(as.factor(df_cf$firmid))

Fitting the causal forest

clusters is passed explicitly – the same reasoning as clustering the standard errors in the interaction models applies here: Type 0 and Type 1 resumes were sent to the same employer within the same short window, so resumes are not independent observations, and the forest needs to know that when estimating variance.

cf <- causal_forest(
  X = X,
  Y = Y,
  W = W,
  clusters = clusters,
  honesty = TRUE
)

Step 1: is there real heterogeneity here at all?

Before looking at any covariate-specific plot, run the calibration test. The differential.forest.prediction coefficient is the one that matters – if it is not distinguishable from zero, the honest conclusion is that the forest did not find heterogeneity beyond the average effect, and the plots below should be read as exploratory rather than confirmatory.

test_calibration(cf)

Step 2: extract per-observation CATE estimates

predict() with no newdata returns out-of-bag predictions by default – each person’s estimate comes from trees that did not include them when deciding splits, avoiding the same in-sample overfitting problem that motivated honesty splitting in the first place.

preds <- predict(cf, estimate.variance = TRUE)
tau_hat <- preds$predictions
tau_se  <- sqrt(preds$variance.estimates)

df_cf$tau_hat <- tau_hat
df_cf$tau_se  <- tau_se

Step 3: Section 5.3 style – CATEs across each covariate

Since every covariate here is binary, there is no continuum to trace a smoothed line across (unlike Figure 5 in Rehill (2025), built on continuous simulated covariates). The direct equivalent is a boxplot comparing the two groups for each covariate, faceted together.

df_long <- df_cf %>%
  select(tau_hat, all_of(covariate_names)) %>%
  pivot_longer(cols = all_of(covariate_names), names_to = "covariate", values_to = "value")

ggplot(df_long, aes(x = factor(value), y = tau_hat)) +
  geom_boxplot(outlier.alpha = 0.3) +
  facet_wrap(~ covariate, scales = "free_x") +
  labs(
    x = "Covariate value (0/1)",
    y = "Estimated CATE (name penalty on callback probability)",
    title = "CATE distribution by covariate value"
  ) +
  theme_minimal()

Step 4: statistical backup – Best Linear Projection

A boxplot difference is suggestive, not proof. For a binary covariate, the BLP coefficient is mathematically the same quantity as the difference between the two boxes’ means, but with a properly resampled standard error and p-value attached – this is the number to actually cite, not the picture.

blp_results <- best_linear_projection(cf, X[, covariate_names])
print(blp_results)

Step 5: spotlight comparison for language_skills

Since this connects directly back to Interaction Model 1 (interaction1_language_signal.Rmd), it’s worth a dedicated, cleaner comparison: group means with confidence intervals rather than a full boxplot, which reads more like the coefficient-style output already used elsewhere in this project.

language_summary <- df_cf %>%
  group_by(language_skills) %>%
  summarise(
    mean_tau = mean(tau_hat),
    se_tau   = sd(tau_hat) / sqrt(n()),
    n        = n()
  )

ggplot(language_summary, aes(x = factor(language_skills), y = mean_tau)) +
  geom_col(fill = "steelblue", width = 0.5) +
  geom_errorbar(aes(ymin = mean_tau - 1.96 * se_tau, ymax = mean_tau + 1.96 * se_tau),
                width = 0.15) +
  labs(
    x = "Language skills listed (0/1)",
    y = "Mean estimated CATE",
    title = "Forest-estimated name penalty, by language signal"
  ) +
  theme_minimal()

Reading this alongside Interaction Model 1: the BLP coefficient on language_skills from Step 4 is the forest’s version of the W:language_skills coefficient from the linear interaction model. If the two roughly agree in sign, size, and significance, that’s evidence the forest confirms the earlier null result. If they diverge, that’s evidence of heterogeneity the single pre-specified linear interaction missed – either way, report both numbers side by side rather than the plot alone.
