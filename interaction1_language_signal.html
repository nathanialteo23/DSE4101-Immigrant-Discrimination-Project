Base treatment (fixed across all interaction models in this series): W = 1(type == 1) vs. type == 0, restricted to name_ethnicity %in% c("Canada", "Chinese", "Indian", "Pakistani"). Type 0 to Type 1 changes only the applicant’s name — education and work-experience origin are held at “Canadian” for both — so W isolates the pure name effect, uncontaminated by the foreign-credential confounds present in Types 2–4. This is narrower than the Type 0–4 comparison used in the Table 4/5 baseline replication, and matches TC’s instruction to restrict the causal forest step to this cleaner contrast.

This model’s moderator: language_skills, i.e. whether the resume lists additional language fluency. This directly operationalizes the statistical discrimination test in Oreopoulos (2011) and Phelps (1972): the name penalty should shrink when a resume supplies a stronger, unambiguous productivity signal.

On standard errors. The original Stata code uses robust SEs only, never clustering. Our own group proposal specifies clustering by firmid instead, since ~4 resumes are sent to each employer in most waves. Both are reported below side by side so the deviation is explicit and auditable rather than silently substituted.

Sample construction

df_int1 <- df %>%
  filter(
    type %in% c(0, 1),
    name_ethnicity %in% c("Canada", "Chinese", "Indian", "Pakistani")
  ) %>%
  mutate(
    W              = as.numeric(type == 1),   # 1 = foreign name (Type 1), 0 = Type 0 baseline
    fall_data      = factor(fall_data),
    # Type 0/1 never carry foreign-credential controls (reference/accreditation/
    # legal are structurally undefined here, same logic as the Table 5 Type-0
    # branch), so those are excluded from the control set below.
    female                 = ifelse(is.na(female), 0, female),
    ba_quality              = ifelse(is.na(ba_quality), 0, ba_quality),
    extracurricular_skills  = ifelse(is.na(extracurricular_skills), 0, extracurricular_skills),
    ma                      = ifelse(is.na(ma), 0, ma),
    same_exp                = ifelse(is.na(same_exp), 0, same_exp),
    exp_highquality         = ifelse(is.na(exp_highquality), 0, exp_highquality),
    language_skills          = ifelse(is.na(language_skills), 0, language_skills)
  )

Model: callback ~ W * language_skills + controls

# (1) Robust SEs only -- matching Oreopoulos's original approach
m_robust <- lm_robust(
  callback ~ W + language_skills + W:language_skills + female + ba_quality +
           extracurricular_skills + ma + same_exp + exp_highquality + fall_data,
  data = df_int1, se_type = "HC1"
)

# (2) Clustered by firmid
m_clustered <- lm_robust(
  callback ~ W + language_skills + W:language_skills + female + ba_quality +
             extracurricular_skills + ma + same_exp + exp_highquality + fall_data,
  data = df_int1, clusters = firmid, se_type = "CR2"
)

The coefficient of interest is W:language_skills. A negative and significant estimate means listing language fluency closes the name penalty (consistent with statistical discrimination); a near-zero or positive estimate means the penalty persists regardless of the signal (harder to reconcile with statistical discrimination alone, and more consistent with a taste-based component).
